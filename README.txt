DETAIL DESK — QUICK START
HarborNestDigital

1. Unzip this folder. On a computer, open index.html in a current Chrome, Edge, Firefox or Safari browser.
2. Add a client, their vehicle and a service before creating a booking. Set job status and amount paid as you work.
3. Use Customize & backup to select theme, font, spacing, cards and contrast. Download JSON backup regularly.
4. To move data to another device, export backup on the old browser and import it on the new one.
5. Data is saved only in the browser profile on this device. It does not sync automatically. Clearing site/browser data can erase it.
6. For phone use, host these files over HTTPS; open the link and choose Add to Home Screen. Offline use after installation requires an initial online visit.
7. Invoices open a print window; allow popups if prompted. Payment records are manual; no payments are processed.

This is a digital browser app, not an online booking portal or shared staff database. Keep a separate backup outside your browser. Contact HarborNestDigital through your Etsy order for help.
