Thank you for choosing Detail Desk

HarborNestDigital · Car detailing business organizer

Start in three steps

  1. Unzip the downloaded folder. Keep all files together and open index.html in a current browser.
  2. Add a client and vehicle, create your service menu, then add a booking. The dashboard and reports update from your entries.
  3. Record job status, amount paid, expenses and supply levels. Print an invoice from Invoices.

Make it yours

Open Customize & backup. Change your business name and currency display, pick one of four themes, choose a modern, classic or large font, adjust spacing and card style, and turn on high contrast. Changes save automatically. Restore appearance defaults resets only the look.

Currency selection changes labels and symbols; it does not exchange-convert saved amounts.

Keep and move your records

Choose Download JSON backup regularly and store the file safely. On another device, open Detail Desk and choose Import JSON backup. Import replaces records currently on that browser, so export its data first. Clearing browser data or using private browsing can remove records. There is no automatic cross-device sync, shared account, online customer booking or payment processing.

Phones and offline use

On a computer, the unzipped folder opens directly. For a phone, the seller must provide a working HTTPS link or you can host the files yourself. Open the link once online. In Safari use Share → Add to Home Screen; in Chrome use the browser menu → Add to Home screen or Install. After the initial hosted visit, the app can cache its files for offline access. Browser storage remains specific to that device and browser.

Common fixes

  • Blank records? Check that you are using the same browser profile, or import your JSON backup.
  • Invoice did not open? Allow popups for the app and try Print invoice again.
  • Install option missing? Use a current browser on an HTTPS page. Opening a file directly may not offer installation.
  • Restore failed? Choose a JSON backup exported from Detail Desk.
